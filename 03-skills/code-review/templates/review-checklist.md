# 代码审查检查清单

## 安全检查清单
- [ ] 没有硬编码的凭证或密钥
- [ ] 对所有用户输入进行输入验证
- [ ] SQL 注入防护（参数化查询）
- [ ] 状态变更操作的 CSRF 防护
- [ ] 使用正确转义的 XSS 防护
- [ ] 受保护端点的认证检查
- [ ] 资源的授权检查
- [ ] 安全的密码哈希（bcrypt、argon2）
- [ ] 日志中没有敏感数据
- [ ] 强制使用 HTTPS

## 性能检查清单
- [ ] 没有 N+1 查询
- [ ] 适当使用索引
- [ ] 在有益的地方实现缓存
- [ ] 主线程上没有阻塞操作
- [ ] 正确使用 async/await
- [ ] 大数据集已分页
- [ ] 数据库连接已池化
- [ ] 正则表达式已优化
- [ ] 没有不必要的对象创建
- [ ] 防止内存泄漏

## 质量检查清单
- [ ] 函数少于 50 行
- [ ] 清晰的变量命名
- [ ] 没有重复代码
- [ ] 正确的错误处理
- [ ] 注释解释"为什么"而不是"是什么"
- [ ] 生产环境中没有 console.log
- [ ] 类型检查（TypeScript/JSDoc）
- [ ] 遵循 SOLID 原则
- [ ] 正确应用设计模式
- [ ] 自文档化的代码

## 测试检查清单
- [ ] 编写了单元测试
- [ ] 覆盖了边界情况
- [ ] 测试了错误场景
- [ ] 存在集成测试
- [ ] 覆盖率 > 80%
- [ ] 没有不稳定的测试
- [ ] Mock 了外部依赖
- [ ] 清晰的测试名称
