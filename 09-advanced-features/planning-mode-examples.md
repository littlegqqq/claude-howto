## 关键要点

### 规划模式的优势

1. **清晰性**：在开始前有清晰的路线图
2. **估算**：时间和工作量估算
3. **风险评估**：尽早识别潜在问题
4. **优先级排序**：任务的逻辑顺序
5. **审批**：执行前进行审查和批准
6. **修改**：根据反馈调整计划

### 何时使用规划模式

✅ **始终用于**：
- 跨多天的项目
- 团队协作
- 关键系统变更
- 学习新概念
- 复杂重构

❌ **无需用于**：
- Bug 修复
- 小型调整
- 简单查询
- 快速实验

### 最佳实践

1. **仔细审查计划**，在批准前
2. **修改计划**，当发现问题时
3. **拆解**复杂任务
4. **估算切实可行的**时间框架
5. **包含回滚**策略
6. **添加成功**标准
7. **为每个阶段规划测试**
